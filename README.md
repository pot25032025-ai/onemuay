# ONE MUAY NEWS PRO

เว็บไซต์ข่าวมวยหลายหน้า สำหรับ GitHub Pages

## โครงสร้าง

- หน้าแรก
- ข่าว
- บทวิเคราะห์
- โปรแกรม
- นักกีฬา
- ติดต่อ
- ระบบค้นหาเบื้องต้น
- SEO แยกแต่ละหน้า
- Sitemap และ Robots
- รองรับมือถือ

## วิธีติดตั้ง

1. แตกไฟล์ ZIP
2. ลบไฟล์เก่าใน Repository `onemuay`
3. ลากไฟล์และโฟลเดอร์ทั้งหมดขึ้น GitHub พร้อมกัน
4. Commit ไปที่ `main`
5. ตั้ง Pages เป็น `main / (root)`

เว็บไซต์: https://pot25032025-ai.github.io/onemuay/
