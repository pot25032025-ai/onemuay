## วิธีติดตั้ง

1. แตกไฟล์ ZIP
2. เข้า Repository `onemuay`
3. อัปโหลดไฟล์ทั้งหมดทับของเดิม
4. เลือก Commit directly to main
5. กด Commit changes
6. ตรวจสอบ Settings → Pages → main → /(root)
